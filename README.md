## ⚡ Instalación y Configuración del Portafolio local

Si deseas levantar o visualizar el código fuente de mi portafolio en tu entorno local:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/M11gueeL/Portfolio.git
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd Portfolio
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el entorno de desarrollo usando Vite (HMR):
   ```bash
   npm run dev
   ```
